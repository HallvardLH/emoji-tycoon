EMOJI TYCOON – GOOGLE PLAY LISTING TRANSLATIONS (DRAFT FOR REVIEW)
===================================================================

Languages: Spanish, Portuguese, German, French, Korean, Indonesian, Turkish, Italian.
Source: store/listing.md (en-US). These are adaptations, not word-for-word translations.

Play limits: app name 30 characters, short description 80, full description 4000.

Notes for the reviewer
----------------------
- Game terms (Emojidex, shiny, essence, trials, gems, combo, the drawing hand) match the app's own translations in i18n/locales, so the listing uses the same words players see in the game.
- The numbers are exact, as in the English (1,594 emojis, 574 upgrades, 153 trophies, 23 buildings), formatted for each locale.
- English says "numbers into the decillions". Spanish, French, Italian and German use the long scale, where "decillion" means 10^60 rather than 10^33, so those versions say "astronomical numbers" instead. Korean does the same, since 조/경 don't line up with "decillion". Portuguese (Brazil) uses the short scale, so it keeps "decilhões".
- Register: informal "you" throughout (tú, você, du, tu, 해요체, kamu, sen, tu), which is normal for casual games in all of these markets.
- Spanish is neutral, for es-419, es-ES and es-US (no vosotros, no regional slang).
- Portuguese is Brazilian (pt-BR). For pt-PT, "você" and the gerunds would need changing.
- French has a non-breaking space before ! ? : ;
- The English full description says you can "collect the production you missed by watching a short ad" and "Contains ads". Ads are currently switched off (ADS_ENABLED = false), so the translations mirror the English, but the English and every translation should drop that part until ads are on. A version without ads is given at the end of each language.
